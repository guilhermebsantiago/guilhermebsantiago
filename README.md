# Hi, I'm Guilherme

Full-stack engineer at [Árvore](https://www.arvore.com.br), where I build product features end to end, from the database to the interface, with TypeScript, React and Next.js, Node.js and NestJS, Elixir and Go on PostgreSQL, MySQL, Redis and AWS. Computer Engineering student at the Federal University of Ceará.

## Open source

- **[Catraca](https://github.com/guilhermebsantiago/catraca)**: a self-hosted anti-abuse engine for platforms that send email, written in Go. CEL rules over Redis counters decide each send in a millisecond or two, start in shadow mode, and only enforce once their measured precision clears a gate. [catraca.guilhermebs.com.br](https://catraca.guilhermebs.com.br)
- **[Rampa](https://github.com/guilhermebsantiago/rampa-cli)**: an accessibility CLI that runs axe-core and asks a language model only what rules cannot decide, one WCAG criterion at a time, keeping a finding only when its evidence is on the page. My undergraduate thesis, on npm as `rampa-cli`. [rampa.guilhermebs.com.br](https://rampa.guilhermebs.com.br)
- **[Leaf](https://github.com/arvoreeducacao/leaf)**: a self-hosted, Notion-style workspace I created at Árvore: a block editor on Yjs with real-time collaboration, offline editing and a built-in MCP server.
- **[Hive](https://github.com/arvoreeducacao/hive)**: Árvore's app for running a fleet of AI coding agents side by side. I contributed the Windows port, the extension system and the themes.
